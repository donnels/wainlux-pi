= FR-001: Reviewed Raster Execution

== Status
Implemented; see the service API contract and HTTP tests.

== Requirement
Compose supported card content into bounded 1-bit raster stages. A user must be able to inspect the exact pixels and placement before execution. Planning and running are separate operations.

== Acceptance

* Review responses contain exact per-stage PNG/SVG pixels, dimensions and physical placement.
* Settings and geometry are validated; content outside the declared etch area is rejected, not clipped.
* A plan names a reviewed stage; only a separate run request accesses the selected machine.
* Software outcome and operator verdict are recorded separately.

== Scope

Content kinds are QR, WiFi QR, text, prepared public assets and checkboxes. Arbitrary image uploads and vector burns are not part of this contract. See the Rust service README and `app/tests/api.rs`.
