= FR-009: Test Ladder

== Status
Implemented for the K6 and simulator; individual steps have machine capability gates.

== Requirement
Expose named machine tests with a stated goal and preview where available. Tests must use the same Rust machine contract as card jobs.

== Acceptance

* `/api/steps` lists the steps supported by the selected machine.
* Supported steps include communication, home, frame, square, limits, blank rows, corner/registration comparisons and QR tests.
* A plan records the expected goal before execution; the API does not label a physical test OK on the operator's behalf.
* Rasters used by tests obey the machine's declared bounds unless the step explicitly tests the calibration envelope.
