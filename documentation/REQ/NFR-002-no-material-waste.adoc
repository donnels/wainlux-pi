= NFR-002: Hardware-Free Test Isolation

== Status
Implemented for simulator-backed automated tests. No real-device dry-run exists.

== Requirement
Automated software tests must be able to exercise the API and composition path without connecting to or moving a laser.

== Acceptance

* Workspace and HTTP contract tests use the simulator and synthetic payloads.
* Simulator mode does not open `/dev/ttyUSB0` or send machine commands.
* A simulator result is never presented as physical acceptance.

A preview is not a real-device no-burn mode. Real mode can burn material and requires operator supervision.
