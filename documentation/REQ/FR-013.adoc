= FR-013: Hardware-Independent Testing

== Status
Implemented through the Rust simulator and workspace tests.

== Requirement
Run API, composition and workflow tests without opening a physical K6 serial port.

== Acceptance

* Tests select the simulator driver and bind only to a local test HTTP port.
* Tests cover review, plan, run, verdict, stage gating and redacted logs with synthetic data.
* Simulator results cannot be treated as evidence of burn quality, device stop or physical completion.

This is simulator testing, not a real-device dry-run mode.
