= FR-013: Hardware-Independent Tests

== Status
Implemented for simulator-backed tests. No real-device dry run exists.

== Requirement
Run API, composition and workflow tests without connecting to or moving a K6.

== Acceptance

* Tests use the simulator, a local HTTP port and synthetic data.
* Simulator mode never opens `/dev/ttyUSB0` or sends machine commands.
* Tests cover review, plan, run, verdict, stage gating and redacted logs.
* Simulator results do not prove burn quality, device stop or physical completion.

Preview is not a real-device dry run. Real mode can move and burn.
