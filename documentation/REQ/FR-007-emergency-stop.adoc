= FR-007: Stop and Cancellation

== Status
Software cancellation implemented; physical stop behavior is not certified.

== Requirement
A stop request must cancel queued work and request a device stop when a device handle exists. It must not automatically retry, start another band or authorize a later stage.

== Acceptance

* Cancellation is checked during connection, upload, wait and between bands.
* The API reports whether a stop request was sent and whether work was cancelled.
* Errors, STOP and uncertain completion do not trigger automatic job, stage or band retries. The driver may retry an individual DATA chunk according to the protocol retry policy.
* An operator confirms motion has stopped before changing placement or proceeding.

A successful HTTP response is not proof of physical rest. Use the machine's physical emergency controls and supervision; this API is not a certified emergency-stop system.
