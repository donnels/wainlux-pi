== Crawler Requests

The root `robots.txt` requests that all crawlers stay out; published HTML also carries `noindex, nofollow, noarchive` metadata from `docinfo.html`. There is no universally enforced no-AI-scan file. These requests are advisory, not authentication, encryption or technical prevention of scraping. The license states the permission boundary; it cannot force a bot to comply or remove material already collected.

`robots.txt` must be served at the hosting origin's `/robots.txt`. A file at a GitHub repository URL or a project Pages subpath does not control `github.com` or the whole `github.io` origin. The docs workflow copies the file into the site output, but origin-root configuration requires control of that host. HTML metadata applies to the rendered project page for crawlers that honor it. Use private hosting or access control when actual exclusion is required.
