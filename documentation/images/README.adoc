= Images

Current diagrams used by the documentation.

* `k6-prot-*.edn` -> `.svg` with Bytefield-SVG (`scripts/generate_diagrams.sh`).
* `system-context.plantuml`, `architecture-rust.plantuml`, `sequence-stage-run.plantuml`, `card-api-clients.plantuml` and `sequence-ghidra-analysis.plantuml` show the current device/client context, service ownership, stage execution, API clients and clean-room handoff. Their PNGs are generated with PlantUML.
* `card-guide.svg` is a generic open-right guide with no submitted content or credentials.
* `card-placement.svg` and `card-items.svg` are generic illustrations of the current K6/card geometry and template coordinates.
* `ui-simulator-preview.png` is a Rust operator UI screenshot with synthetic Wi-Fi values, simulator mode and no burn started. The simulator's 80 x 80 mm profile is not the measured K6 working reach.
* `test-ladder.svg`, `test-case-07a-limit-stairs.svg`, `test-case-07c-seven-squares.svg`, `test-case-08-blank-rows.svg` and `test-case-09-corners.svg` show Rust test coverage/evidence. The 9b comparison is shared from `docker/docker-wainlux-rs/app/assets/test-patterns/vertical-comparison.svg`.
* `capture_20260127_124112.jpg`, `capture_20260127_124223.jpg`, `capture_20260127_124337.jpg` and `capture.2426611769506763096.jpg` are recovered historical cork/PLA close-ups; they are not 9b ladder microscope captures.
