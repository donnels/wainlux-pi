= ADR-007: AsciiDoc

== Status
Accepted; current.

== Decision
Use AsciiDoc for repository documentation, with PlantUML for process diagrams and Bytefield-SVG for packet layouts. Keep sources beside the documents that use them.

== Consequences

* Validate documentation with `./scripts/test_docs.sh` from the repository root.
* Keep generated diagrams reproducible from checked-in source where a generator exists.
