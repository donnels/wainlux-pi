= ADR-002: K6 Serial Transport

== Status
Accepted; current.

== Decision
The Rust `k6` crate owns all K6 protocol framing and communicates through the Linux serial device, normally `/dev/ttyUSB0` at 115200 baud. The CP210x bridge is accessed through the kernel serial driver; the application does not speak USB directly.

The `laser::Machine` contract keeps serial details out of composition and HTTP handling. Host tests use the simulator and do not require a serial device.

== Consequences

* Only the K6 driver opens the serial port.
* A second process must not own `/dev/ttyUSB0` at the same time.
