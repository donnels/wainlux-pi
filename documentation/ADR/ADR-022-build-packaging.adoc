= ADR-022: ARM Packaging

== Status

Accepted; current.

== Decision

Build the laser service for the original Raspberry Pi Zero W (`armv6l`) on a workstation. Target `arm-unknown-linux-musleabihf` and the `arm1176jzf-s` CPU. Do not compile on the Pi.

Use a multi-stage image: a digest-pinned cross-compiler builds the binary, and a minimal ARMv6 runtime image contains the binary and required configuration. Keep build and deployment separate. Deployment requires an explicit target and must not start a laser job.

== Consequences

* The Pi is a runtime target, not a build host.
* The target triple, compiler, runtime platform, and Compose image must remain aligned.
* Build, deployment, and rollback procedures belong in `DEVELOPMENT.adoc`, `documentation/GETTING_STARTED.adoc`, and `scripts/README.adoc`.
