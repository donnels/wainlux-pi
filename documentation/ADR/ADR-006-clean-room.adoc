= ADR-006: Clean-Room Protocol Work

== Status
Accepted; ongoing constraint.

== Decision
Describe observed bytes and device behavior, not vendor source structure or implementation. The current Rust service is independently implemented from observable protocol behavior. Decompiled material was used only as a verification aid; it is not included or translated into the service.

== Consequences

* Keep packet captures, hardware observations and uncertainty distinct from implementation claims.
* Do not copy vendor code, names, comments or design structure.
