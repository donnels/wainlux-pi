Quick guide to using this repository.

== For Users

=== Deploy to Pi

.Start the preloaded ARM image
[source,bash]
----
cd docker/docker-wainlux-rs
docker compose up -d
----

Access: `http://<pi-ip>:8081`. The ARM image must already be loaded on the Pi; this compose file does not build it.

=== Generate Diagrams

.Render the documentation diagrams
[source,bash]
----
plantuml documentation/images/*.plantuml
----

Output: `documentation/images/*.png`

== For Documentation Writers

=== Add Diagram

Create `.plantuml` file in `documentation/images/`:

.Minimal source for a PlantUML diagram
[source,plantuml]
----
@startuml

actor User
User --> System
@enduml
----

.Render a new PlantUML diagram
[source,bash]
----
plantuml images/new-diagram.plantuml
----

.Reference the rendered diagram from AsciiDoc
[source,asciidoc]
----
\image::documentation/images/new-diagram.png[Description]
----

== For Contributors

=== Clone Repository

.Clone the repository
[source,bash]
----
git clone <repo-url> wainlux-pi
cd wainlux-pi
----

=== Follow Style

* DRY - Don't Repeat Yourself
* KISS - Keep It Simple, Stupid
* Hemingway - Short, direct sentences
* No fluff - Essential info only

== Quick Commands

.Run documentation and Rust checks
[source,bash]
----
# Check documentation
./scripts/test_docs.sh

# Test Rust workspace
cd docker/docker-wainlux-rs && cargo test --workspace
----
