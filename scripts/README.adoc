Repository maintenance and documentation utilities.

== Usage

`test_docs.sh`:: Validate all AsciiDoc files render correctly standalone and as includes.
`generate_diagrams.sh`:: Regenerate checked-in documentation diagrams.

== Run

=== Documentation Testing

.Run the documentation validator
[source,bash]
----
# Test all AsciiDoc files for rendering consistency
./test_docs.sh
----

Requires podman. Uses asciidoctor/docker-asciidoctor container image.
