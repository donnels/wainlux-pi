Repository maintenance and documentation utilities.

== Commands

Run these commands from the repository root:

[cols="1,3",options="header"]
|===
| Command | Purpose
| `./scripts/build_laser.sh` | Test the CLI examples and Rust service workspace, then build the ARMv6 image. Does not deploy.
| `./scripts/deploy_laser.sh --target USER@PI-HOST --confirm` | Transfer the image and recreate an idle Pi service. Never starts a laser job.
| `./scripts/analyze_laser_audio.sh RECORDING.m4a` | Analyze DTMF and candidate audio activity in a container. No laser control.
| `./scripts/test_docs.sh` | Check AsciiDoc rendering, links, captions and PlantUML attribution.
| `./scripts/generate_diagrams.sh` | Regenerate protocol SVGs from the EDN sources.
|===
