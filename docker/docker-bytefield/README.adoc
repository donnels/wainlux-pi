= Bytefield-SVG

The container renders checked-in EDN packet specifications as SVG. Its pinned `librsvg` converter also creates PNG companions for every SVG in `documentation/images/`.

From the repository root, run `./scripts/generate_diagrams.sh`. It uses the selected local Bytefield and PlantUML images and regenerates both formats. To build or scan image updates, use `scripts/update_container_image.sh`.

Packet sources and rendered files live in `documentation/images/`.
