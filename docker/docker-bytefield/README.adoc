= Bytefield-SVG

The container renders checked-in EDN packet specifications as SVG.

From the repository root, run `./scripts/generate_diagrams.sh`. The script builds the container when needed and regenerates all packet diagrams.

Packet sources and rendered files live in `documentation/images/`.
