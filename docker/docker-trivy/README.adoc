= Trivy

Digest-pinned scanner wrapper used by image update scripts to block promotion on HIGH or CRITICAL findings.

== Reports

Update scripts save a compact CSV summary beside the image README. The report counts HIGH and CRITICAL vulnerabilities, ignored findings, and secrets. It omits package names and advisory text. `jq` must be installed on the host.

Run commands from the repository root. Replace the image value to scan a different registry image. Use `--exit-code 0` for inspection so findings do not stop the JSON pipeline.

.Scan a registry image and print the compact CSV summary
[source,bash]
----
IMAGE=docker.io/library/alpine:3.24
podman run --rm -v wainlux-trivy-cache:/root/.cache \
  localhost/wainlux-trivy:0.76.2 image --quiet --severity HIGH,CRITICAL \
  --format json --exit-code 0 "$IMAGE" \
  | jq -r --arg image_id "$IMAGE" --arg scanned_utc "$(date -u +%FT%TZ)" \
      -f scripts/trivy-summary.jq
----

.Example summary output (illustrative)
[source,csv]
----
"record","metric","value"
"metadata","image_id","docker.io/library/alpine:3.24"
"metadata","scanned_utc","2026-11-17T12:00:00Z"
"count","vulnerability_critical","0"
"count","vulnerability_high","2"
"count","ignored_critical","0"
"count","ignored_high","0"
"count","secret_critical","0"
"count","secret_high","0"
----

Use the detail filter when the summary shows findings. It emits CVE IDs, package names, installed and fixed versions. Secret output contains rule identifiers and locations, never the matched secret value.

.Write detailed findings to CSV
[source,bash]
----
IMAGE=docker.io/library/alpine:3.24
podman run --rm -v wainlux-trivy-cache:/root/.cache \
  localhost/wainlux-trivy:0.76.2 image --quiet --severity HIGH,CRITICAL \
  --format json --exit-code 0 "$IMAGE" \
  | jq -r -f scripts/trivy-findings.jq > /tmp/alpine-findings.csv
----

.Example detailed output (truncated)
[source,csv]
----
"record","severity","identifier","component","installed_version","fixed_version"
"vulnerability","CRITICAL","CVE-2026-111497","brotli-libs","1.2.0-r0","1.2.1-r0"
"vulnerability","HIGH","CVE-2026-92392","curl","8.22.0-r0","8.23.0-r0"
... remaining findings omitted ...
----

For a local image, save it as an archive and mount the containing directory read-only:

.Scan a local image archive and print detailed CSV
[source,bash]
----
podman save --output /tmp/candidate.tar localhost/example:tag
podman run --rm -v /tmp:/scan:ro -v wainlux-trivy-cache:/root/.cache \
  localhost/wainlux-trivy:0.76.2 image --input /scan/candidate.tar --quiet \
  --severity HIGH,CRITICAL --format json --exit-code 0 \
  | jq -r -f scripts/trivy-findings.jq
----

Use `--exit-code 1` when the command should fail on HIGH or CRITICAL findings. The update scripts use that gate and preserve the previous selected image when scanning fails. See the [Trivy reporting guide](https://trivy.dev/docs/latest/guide/configuration/reporting/) for supported output formats.
