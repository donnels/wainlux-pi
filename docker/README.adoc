Docker Compose projects for the laser service and supporting tools live here.

The Pi runs a prebuilt ARMv6 image. Compose does not build it.

.Start the preloaded Rust service on the Pi
[source,bash]
----
cd docker/docker-wainlux-rs
docker compose up -d
----

The service uses `/dev/ttyUSB0` and port `8081`.
