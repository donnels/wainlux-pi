Container definitions for the Rust laser service and supporting tools live here.

== Compose Files

The current K6 service and its Pi deployment compose file are in `docker/docker-wainlux-rs/`.

.Start the preloaded Rust service on the Pi
[source,bash]
----
cd docker/docker-wainlux-rs
docker compose up -d
----

The image is cross-built and loaded on the Pi; compose does not build it. The service uses `/dev/ttyUSB0` and port `8081`.

== MCP Client Draft

`docker/docker-mcp/` contains a separate Streamable HTTP MCP service, assumed to run on the Pi Zero host for now. It exposes discovery and preview only; it cannot start or stop laser work. See its README before deployment.
