Docker Compose projects for the laser service and supporting tools live here.

The Pi runs a prebuilt ARMv6 image. Compose does not build it.

.Start the preloaded Rust service on the Pi
[source,bash]
----
cd docker/docker-wainlux-rs
docker compose up -d
----

The service uses `/dev/ttyUSB0` and port `8081`.

[WARNING]
====
All tool containers must use **local Dockerfiles** with **pinned base images**. Never use `:latest` tags.

The `:latest` tag creates unacceptable supply chain risk:
* No version history — if `:latest` breaks, we cannot determine what version was previously working
* No rollback path — there is no tag to revert to
* Implicit updates — new versions may be pulled automatically, introducing breaking changes or vulnerabilities
* Audit difficulty — cannot trace exactly what was used in historical builds

With local Dockerfiles in git:
* Git is the source of truth — all container definitions are in the repository
* Versioned by commit — every change to a Dockerfile creates a new, auditable version
* Rollback via git — `git checkout <commit>` restores the exact container that was used
* Scan before merge — vulnerability scanning can be part of the CI/CD pipeline

See <<adr-029-container-security,ADR-029: Local Container Builds for Supply Chain Security>> for the full rationale.
====
